# Security Policy

## Supported scope

This repository contains educational Ansible examples. Review all content before running it, particularly tasks that install software, manage services, modify permissions, or use privilege escalation.

## Reporting a vulnerability

Please avoid opening a public issue for a suspected security vulnerability. Contact the repository maintainer privately through the contact options on the [maintainer's GitHub profile](https://github.com/SandeepKomal) and include a concise description, affected path, impact, and safe reproduction steps.

Do not include live credentials, private keys, personal data, or sensitive infrastructure details in the report. Please allow time for investigation and a fix before public disclosure.

## If a secret is exposed

Revoke or rotate it immediately. Removing the value from the latest commit may not remove it from Git history or clones.
