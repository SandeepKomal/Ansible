      Start on your machine

      Install Ansible

      Needs Python 3 on your machine and SSH access to a test host you own.

      # 1. Get the course and its playbooks
git clone https://github.com/SandeepKomal/Ansible.git
cd Ansible

# 2. Install Ansible in a virtual environment
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ansible ansible-lint

      Your first run

      Point the example inventory at your test host, then preview before changing anything.

      # 3. Your inventory (do not commit it)
cp inventory/hosts.ini.example inventory/hosts.ini

# 4. Check, preview, run
ansible all -m ansible.builtin.ping
ansible-playbook playbooks/hello.yml --check --diff
ansible-playbook playbooks/hello.yml
